# 雨课堂播放按钮助手

适用于雨课堂视频课程页的浏览器用户脚本，当前版本 **1.5.4**。提供连续播放、完成度验证、完成后切换下一视频，以及断网暂停和有限恢复。

## 安装

1. 在电脑浏览器中安装用户脚本管理器，例如 Tampermonkey。
2. 打开仓库中的 [`雨课堂播放按钮助手.user.js`](./雨课堂播放按钮助手.user.js)，点击 **Raw**。如果脚本管理器弹出安装页，点击安装。
3. 如果没有弹出安装页，在脚本管理器中选择“添加新脚本”，删除默认内容，粘贴上述文件的完整内容并保存。
4. 打开或刷新雨课堂视频课程页，右下角会出现助手面板。请只启用一个版本。

脚本适配的页面：`https://www.yuketang.cn/ai-workspace/lms-graph/*`。

## 使用

1. 展开左侧课程目录，将浏览器标签页静音。
2. 点击助手的“开始连续播放”，保持课程标签页可见。
3. 当前视频完成度达到 100% 或播放器上方显示“已完成”后，助手验证下一课加载并继续播放。
4. 点击“停止并暂停”可结束自动流程。打开完成度详情或其他弹窗也会停止助手，关闭弹窗后需手动重新开始。

鼠标移出浏览器或远程控制使网页失去键盘焦点时，只要课程标签页仍可见，助手就能继续运行。切换标签页或最小化浏览器会触发隐藏页面等待或停止规则。

视频结束后若完成度不足，助手先等待 60 秒，随后最多从头补播一次；仍未完成则停止并提示手动处理。助手以 1 倍速播放，不伪造页面焦点、可见性或观看记录。平台是否成功记录进度仍需以课程页为准。

完整流程、恢复限制和诊断说明见 [`使用说明.md`](./使用说明.md)。

## 更新

下载最新脚本并在用户脚本管理器中替换旧内容，保存后刷新课程页。

## 本地验证

安装 Node.js 后，在仓库目录运行：

```sh
node --check "雨课堂播放按钮助手.user.js"
node tests/verify-helper.cjs
```

测试使用模拟页面验证状态转换，不连接雨课堂。真实平台的播放器响应、自动播放权限和观看记录需要在课程页验证。页面结构变更可能影响兼容性；遇到问题可提交 Issue，附助手状态和脱敏后的诊断信息。
